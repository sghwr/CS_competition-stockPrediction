# 股票预测任务分析报告：排序学习与收益率预测的错配问题

## 摘要

本报告基于对THU-BDC2026股票预测baseline的深入分析，揭示了当前模型存在的根本问题：**排序学习（Learning to Rank）框架与收益率Top5选择任务之间存在严重错配**。通过实际数据验证，模型虽能选出正收益股票，但完全错过真正的高收益机会，导致基于模型分数优化权重的策略效果有限。

## 1. 问题背景

### 1.1 比赛任务要求
- **目标**：基于历史数据预测未来一周（T+1到T+5）收益最大的股票组合
- **输出**：不超过5只股票及权重，权重总和≤1
- **评估**：按投资组合总收益率排名
- **公式**： $R_{total} = \sum_{i=1}^{n} \left( w_i \times \frac{P_{i,T+5}^{open} - P_{i,T+1}^{open}}{P_{i,T+1}^{open}} \right)$

### 1.2 Baseline实现概况
- **模型架构**：StockTransformer（时序编码+股票间注意力）
- **特征工程**：158个Alpha特征 + 39个技术指标
- **训练目标**：排序学习（Learning to Rank）
- **损失函数**：WeightedRankingLoss（强调top-k样本）
- **评估指标**：final_score（模型Top5收益 vs 理论最大收益）

## 2. 分析方法

### 2.1 数据准备
- **训练数据**：`data/train.csv`（2024-01-02 到 2026-03-06）
- **测试数据**：`data/test.csv`（2026-03-09 到 2026-03-13）
- **预测基准日**：T = 2026-03-06（训练数据最新日期）
- **预测窗口**：T+1 = 2026-03-09，T+5 = 2026-03-13

### 2.2 分析流程
1. **模型推理**：使用训练好的`best_model.pth`对300只沪深300成分股预测排序分数
2. **收益率计算**：从test.csv提取每只股票T+1和T+5开盘价，计算5日收益率
3. **相关性分析**：计算模型分数与实际收益率的统计关系
4. **性能评估**：分析模型Top5选择能力与真实Top5的差距

## 4. 根本问题分析

### 4.1 设计目标错配
**Baseline实际任务**：排序学习（Learning to Rank）
- 目标：让高收益股票**相对排名靠前**
- 评估：排名准确性（如NDCG、MAP）
- 输出：任意尺度的排序分数

**比赛要求任务**：收益率Top5选择
- 目标：选出**绝对收益最高**的5只股票
- 评估：收益率数值大小
- 输出：收益率预测值

### 4.2 代码层面证据
#### 4.2.1 损失函数设计问题
```python
# train.py 第157行：识别当前batch中的top-k样本
_, top_indices = torch.topk(y_true, k, dim=1)  # 使用真实收益率

# 第160-162行：给top-k样本更高权重
weights[i, top_indices[i]] = self.weight_factor
```

**问题**：
1. **跨batch不一致**：不同交易日的top股票不同，模型学习的是"当前环境下谁相对更好"
2. **未学习收益幅度**：只关注排名顺序，不关注收益率数值大小
3. **局部最优**：在每个batch内优化，但全局来看可能不是真正的高收益股票

#### 4.2.2 模型输出层问题
```python
# model.py 第97-102行：最终输出层
self.score_head = nn.Sequential(
    nn.Linear(config['d_model'] // 4, config['d_model'] // 4),
    nn.ReLU(),
    nn.Dropout(config['dropout'] * 0.5),
    nn.Linear(config['d_model'] // 4, 1)  # 输出单个分数值
)
```

**问题**：输出是**任意尺度**的分数，没有与收益率建立定量关系。

#### 4.2.3 评估指标偏差
```python
# train.py 第213行：final_score计算
final_score = (pred_return_sum - random_return_sum) / (denominator + 1e-12)
```

**问题**：`final_score`衡量的是**相对于随机策略的改进**，而不是**绝对收益率水平**。模型可能满足于比随机略好，而不追求最高收益。

### 4.3 数据分布问题
**市场环境特征**（2026-03-09到2026-03-13）：
- 收益率分布右偏：少数股票获得极高收益（0.18-0.29）
- 大部分股票微涨：65.67%正收益，但幅度小（0-0.05）
- 模型陷入"安全区"：选择稳定正收益股票，避开高风险高收益股票

## 5. 对权重优化策略的影响

### 5.1 原思路评估
**提出的优化策略**：冻结Transformer权重，优化股票权重和买入阈值

**前提条件**：
1. 模型分数与收益率有稳定关系 ✓（不成立）
2. 分数能反映收益预期幅度 ✓（不成立）
3. Top5选择基本正确 ✓（不成立）

**实际状况**：
1. **分数-收益率关系弱**：Spearman=0.106，不能作为权重依据
2. **分数无经济意义**：高分数≠高收益，负分数≠低收益
3. **Top5选择错误**：完全错过真正高收益股票

### 5.2 权重优化风险
如果基于当前模型分数优化权重：

1. **错误分配权重**：给"伪高收益"股票过高权重
2. **错过机会**：低配或零配真正高收益股票
3. **放大错误**：优化过程会强化模型的系统性偏差
4. **过拟合风险**：在错误信号上优化6个连续参数

### 5.3 等权重策略分析
**当前baseline策略**：固定等权重0.2（5只股票）

**表现**：
- 模型Top5平均收益率：0.0252
- 随机策略平均收益率：0.0128
- 超额收益：0.0124（+1.24%）

**评价**：
- ✅ **稳健**：避免权重分配错误
- ✅ **简单**：无需复杂优化
- ⚠️ **保守**：错过高收益机会
- ⚠️ **次优**：收益率仅排72.33百分位

## 6. 解决方案建议

### 6.1 方案一：回归任务改造（推荐）
**核心思想**：将排序学习改为收益率回归预测

**实施步骤**：
1. **修改输出层**：`nn.Linear(config['d_model'] // 4, 1)` → 直接输出收益率预测
2. **更换损失函数**：`WeightedRankingLoss` → `MSELoss` 或 `HuberLoss`
3. **调整评估指标**：`final_score` → 收益率预测准确率
4. **数据标准化**：对收益率标签进行适当缩放

**优势**：
- 直接优化比赛目标（收益率预测）
- 预测值可直接作为权重分配依据
- 保持现有特征工程和架构

### 6.2 方案二：多任务学习
**核心思想**：同时学习排序和回归任务

**架构设计**：
```
特征 → Transformer共享层 → 多任务头
                         ├→ 排序头（现有）
                         └→ 回归头（新增）
```

**损失函数**：
```
总损失 = α × 排序损失 + β × 回归损失
```

**优势**：
- 兼顾排名准确性和收益率预测
- 可渐进迁移到回归任务
- 提供更多信号用于决策

### 6.3 方案三：特征工程增强
**新增特征维度**：
1. **市场资金流向**：北向资金、主力资金净流入
2. **情绪指标**：新闻情感分析、社交媒体热度
3. **宏观因子**：利率变化、通胀预期、政策信号
4. **另类数据**：分析师评级变化、机构持仓变动

**实施方法**：
- 扩展`utils.py`中的特征工程函数
- 确保数据可公开获取（比赛要求）
- 注意特征时效性和计算复杂度

### 6.4 方案四：模型集成
**组合策略**：
1. **当前模型**：作为"正收益筛选器"
2. **回归模型**：预测收益率幅度
3. **规则模型**：基于简单技术指标
4. **集成方法**：加权平均或stacking

**决策流程**：
```
当前模型分数 → 初选股票池（如Top20）
回归模型预测 → 收益率排序
最终选择 → Top5 + 权重分配
```

## 8. 风险与挑战

### 8.1 技术风险
1. **过拟合风险**：收益率预测难度大，易过拟合噪声
2. **数据时效性**：市场模式可能随时间变化
3. **计算资源**：增加特征和模型复杂度需要更多资源

### 8.2 策略风险
1. **黑箱问题**：深度学习模型可解释性差
2. **极端事件**：模型可能无法应对市场突变
3. **交易成本**：实际交易中需考虑滑点和手续费

### 8.3 比赛要求风险
1. **数据来源限制**：必须使用公开免费数据
2. **模型可复现性**：需要完整记录实验过程
3. **创新性要求**：需要在baseline基础上显著改进

## 9. 结论

### 9.1 核心结论
1. **任务错配是根本问题**：排序学习框架不适合收益率Top5选择任务
2. **模型有基本能力但不足**：能选出正收益股票，但错过高收益机会
3. **权重优化前提不成立**：需要先解决收益率预测问题

### 9.2 建议优先级
**第一优先级**：将排序学习改为回归任务
- 最直接解决根本问题
- 技术改动相对简单
- 预期效果提升明显

**第二优先级**：增强特征工程
- 提供更多预测信号
- 可与其他方案结合
- 符合比赛创新性要求

**第三优先级**：优化权重分配策略
- 在可靠预测基础上进行
- 可显著提升最终收益
- 体现策略设计能力

### 9.3 预期收益
通过实施上述改进，预期可实现：
1. **Top5命中率提升**：从0%提升到20-40%
2. **收益率水平提高**：从0.025提升到0.05-0.10
3. **比赛排名进步**：从baseline水平进入前列
